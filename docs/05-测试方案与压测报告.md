## 4. 结论与工程发现

1. **达标**：并发 ≤200 时网关自身转发开销 P95=60ms（PRD 目标 <100ms ✅），全链路 0 失败。
2. **发现（Windows 环境限制）**：Go 在 Windows 的 listen backlog 约 200，瞬时并发超过该值会出现**连接排队（尾部延迟飙升）与少量连接拒绝**（300 并发 8 失败、500 并发 101 失败）。这是平台限制而非网关代码缺陷。
3. **生产建议**（面试可讲）：
   - 前置反向代理（nginx/云 LB）吸收连接队列，网关保持无状态水平扩容；
   - 生产部署于 Linux（backlog 由 somaxconn 控制，可调大）；
   - 压测在 Linux + 网关直连场景重跑以验证 S2 全量达标。
