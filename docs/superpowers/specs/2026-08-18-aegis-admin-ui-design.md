# AEGIS 管理后台 UI 布局优化设计

## 设计读取

这是一个面向技术运营人员的 AI 网关管理后台重设计。采用稳定专业、工程化、低干扰的视觉语言，继续使用现有 Ant Design 作为组件基础。

- DESIGN_VARIANCE: 5
- MOTION_INTENSITY: 3
- VISUAL_DENSITY: 4
- 主题：浅色工作区 + 深蓝导航

## 范围与约束

本次只优化核心业务后台页面：仪表盘、Key 管理、提供商、调用日志、账单、评测。

保持不变：

- 登录页
- 路由、页面信息架构和菜单名称
- 接口调用、请求参数、表单字段和数据行为
- 现有 Ant Design 组件体系
- 现有错误、加载、空数据和权限行为

## 当前审计结论

现有后台已经具备完整的业务页面和交互能力，主要视觉问题集中在公共壳层与页面节奏：

- 侧栏和顶部栏较为朴素，品牌、当前页面和导航层级不够明显。
- 页面标题、内容卡片和操作区缺少统一结构。
- 内容区使用固定小间距，桌面宽屏的可读性和呼吸感不足。
- 仪表盘指标卡、图表卡与业务表格页的层级语言不统一。
- 窄屏下需要更明确的侧栏折叠、横向表格和工具栏布局规则。

## 目标体验

用户进入后台后应能快速回答三个问题：我现在在哪个模块、系统当前状态如何、下一步可以做什么。

视觉上保持工程产品的可靠感，但减少默认后台模板感：通过定制主题 token、空间节奏、选中态、页面标题和操作区层级实现提升，不使用装饰性渐变、玻璃拟态或大幅动效。

## 视觉系统

### 颜色

- 主导航：深蓝 `#10253F`
- 工作区背景：浅灰蓝
- 内容表面：白色
- 主操作：蓝色
- 成功：绿色
- 警告：橙色
- 错误：红色
- 正文：深蓝灰
- 辅助文本：中性灰

颜色需通过 Ant Design `ConfigProvider` 统一配置，页面内尽量不继续散落硬编码颜色。

### 形状与层级

- 统一使用中等圆角，避免卡片、按钮和输入框各自使用不同半径。
- 卡片使用轻边框或低强度阴影，不使用厚重阴影。
- 页面背景与白色内容表面形成稳定对比。
- 选中导航使用浅蓝背景和左侧强调线，避免只依赖文字颜色。

### 排版与间距

- 页面标题区统一为标题、简短说明和右侧操作区。
- 内容区采用更宽的最大容器和更有呼吸感的页面内边距。
- 统一卡片标题、工具栏与表格的垂直节奏。
- 继续使用系统无衬线字体，避免引入新字体依赖。

## 页面设计

### 公共壳层

- 重做 `SideLayout` 的侧栏品牌区、菜单、顶部栏和内容容器。
- 侧栏在桌面端保持深蓝，在窄屏通过 Ant Design breakpoint 折叠。
- 顶部栏保留登出操作，并强化当前工作区的视觉连接。
- 通过公共类名或主题 token 统一页面背景、内容宽度、卡片和标题区。

### 仪表盘

- 保留四项统计指标和近 7 日趋势图。
- 指标卡加强数字层级，弱化标题和辅助文案。
- 图表卡的标题与数据来源信息分层，避免数据来源抢占主要注意力。
- 加载、错误和空趋势状态沿用现有行为，只调整布局和视觉样式。

### Key、提供商、日志、账单

- 统一页面标题与说明区。
- 统一卡片标题、筛选/创建操作区和表格容器。
- 保留现有分页、横向滚动、弹窗、确认和状态标签。
- 让主操作按钮固定在工具栏的清晰位置，窄屏时允许工具栏换行。

### 评测

- 保留数据集、样本和运行报告的现有 Tabs、Modal、Drawer 和 API 行为。
- 强化数据集选择区与主要动作的层级。
- 保留表格中的标注、报告和运行操作，不改变字段和交互含义。
- 通过更合理的间距与分区降低评测页的密集感。

## 动效与响应式

- 动效强度为 3，只使用 Ant Design 默认过渡、按钮反馈和加载状态。
- 不新增滚动监听、复杂动画库或装饰性动效。
- 使用现有 Ant Design 响应式能力，桌面侧栏折叠，内容区保持可读宽度。
- 宽表格继续横向滚动，不强行压缩列内容。
- 所有主要操作在窄屏保持可见、可点击和不被遮挡。

## 验证策略

- 运行 TypeScript/Next.js 构建或项目已有 lint 命令。
- 检查六个核心页面的路由仍可访问，登录鉴权行为不变。
- 检查桌面与窄屏下侧栏、页面标题、卡片、工具栏和表格布局。
- 检查加载、错误、空数据、弹窗和表单交互没有回归。
- 检查颜色对比度、键盘焦点和按钮文本可读性。

## 不做的事情

- 不改登录页。
- 不改后端接口和数据模型。
- 不改 URL、菜单标签、表单字段名或埋点意图。
- 不引入新的 UI 框架、字体或复杂动画依赖。
- 不进行与 UI 优化无关的业务重构。
