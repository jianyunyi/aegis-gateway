# AEGIS — 企业大模型网关与智能观测平台

> 项目代号：**AEGIS**（All-in-one Enterprise Gateway & Intelligence Service）
> 仓库名：`aegis-gateway`
> 定位：统一的企业大模型接入网关 —— 路由、限流、计费、观测、评测一站式平台

本目录按**真实企业级研发流程**管理项目全部文档。所有决策先写文档、评审确认后进入开发。

## 四、技术栈约束

前端三件套 + TypeScript + React + Next.js ｜ Go + Gin + Gorm ｜ Redis + MySQL ｜ Docker

## 五、关键约定

- 所有需求变更必须回到 PRD 更新并记录变更原因（变更管理）
- 每个关键架构决策写 ADR（见技术方案文档），评审通过后不得随意推翻
- 每期结束必须有一个可演示的 Demo 点（企业里叫"可工作的软件"）
- 代码评审制度在 04-开发规范.md 中定义
